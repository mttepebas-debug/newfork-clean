Postal coordinate suggestions use Zippopotam.us / GeoNames at request time.
Only country and postal code are sent; no address or employee data is sent.
Postal results are not persisted or redistributed as a database by this feature.
Postal centroids and timezone boundaries can be approximate; manual selection is authoritative.

- https://www.zippopotam.us/
