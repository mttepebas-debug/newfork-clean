   - Postgres SQL correlation-shadowing bug pattern: an unqualified bare column reference inside a correlated subquery, when a same-named column exists in the subquery's OWN immediate FROM-scope, resolves to the LOCAL column (self-referential tautology, e.g. `where d.draft_id=draft_id` inside `select ... from schedule_draft_shifts d where d.draft_id=draft_id` resolves `draft_id` to `d.draft_id` itself, matching every row in the table) instead of the intended outer/correlated value — must use an explicit `(select draft_id from pub_ids)` scalar subquery to disambiguate.
