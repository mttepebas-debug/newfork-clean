## Default mode config

Default = `full`.

Env var wins:
```bash
export CAVEMAN_DEFAULT_MODE=ultra
```

Config file `~/.config/caveman/config.json`:
```json
{ "defaultMode": "lite" }
```

`"off"` kill auto-start. Manual `/caveman` still work.

Order: env var > config file > `full`.
