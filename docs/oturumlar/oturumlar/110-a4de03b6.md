### 2026-08-03T23:41:12.876Z

Tracked as `GAP-9` in `.planning/REQUIREMENTS.md`.

E2E specs rely on Playwright's default 5s `expect` timeout when asserting a route anchor, but heavy app routes need a cold Vite dev-server compile on their first visit in a worker. That makes specs fail cold and pass warm.

Confirmed case:

    pnpm exec playwright test --config=playwright.config.ts e2e/mvp-schedule-lifecycle.spec.ts --workers=1 --repeat-each=2 --reporter=line
    # iteration 1 fails, iteration 2 passes

It fails at `e2e/mvp-schedule-lifecycle.spec.ts:235`:

    await expect(page.getByTestId("my-schedule-page")).toBeVisible();

on `/app/employee-hub/schedule`, after the entire manager save+publish flow has already succeeded. Nothing about the assertion is wrong — it just does not wait long enough for a first compile.

`playwright.config.ts` sets `retries: 2` when `process.env.CI`, so CI usually recovers. That is the actual problem: a suite that flakes teaches people to re-run instead of read failures, and a real regression then reads as noise.

Two specs already work around this individually with an explicit longer anchor timeout (`e2e/mock/employee-bulk-import.spec.ts` uses `DIRECTORY_READY_MS = 30_000`, `e2e/mock/schedule-retroactive-edit.spec.ts` uses 30_000 on the grid cell). Doing it one spec at a time is not the fix.

Preferred approach: raise the default `expect.timeout` in `playwright.config.ts` (the route-performance lane has its own per-case budgets in `e2e/route-performance/route-matrix.ts` and must keep asserting them, so make sure a raised global default does not weaken those). Then remove the per-spec workarounds that are no longer needed, and sweep the remaining specs for anchors that would still be tight on a cold route.

Do not lower `retries`. Verify by running the full mock lane twice from a cold `.vite` cache with `--workers=1`, matching how CI runs it.

Note: several sessions are editing files under `e2e/` concurrently — check `git status` first and stage only the files you change, by explicit path.
